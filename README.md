## 四种模式

### 闯关模式（单人）

十关冒险，清光场上的怪物就能进下一关，第 10 关通关。

- 第 1 关起陆续出现三种小怪，第 5 关和第 10 关是**鲁鲁旦 BOSS 战**。
- BOSS 有 8 点生命，分**试探 / 认真 / 暴走**三个阶段；暴走阶段会放毒刺，还能炸掉场上的硬墙。
- 每关开局有敌情档案，先告诉你这关会遇到什么。

### 计时拆砖（单人）

**180 秒**内炸光全场软砖。屏幕上有倒计时和剩余软砖数，时间到还没清完就算输。

### 同屏对战（双人）

两个人一个键盘，先得 **2 分**者获胜。

- 双方各有独立的**选角准备室**：各选各的角色，各自按准备，两人都准备好才能开局。
- 一人用手柄、一人用键盘也可以，设备各算各的。
- 90 秒后进入死亡加速并逐步清空软砖，45 秒后仍未分胜负则平局。

### 联机对战（局域网双人）

两台电脑各控制一名玩家，沿用先得 **2 分**的对战规则；这是第四种独立模式，同屏对战仍然保留。

1. 两台电脑使用相同版本的桌面游戏，接入同一局域网。
2. 一方选择“联机对战 → 创建房间”，把界面显示的房主 IP 告诉另一方。
3. 另一方填写房主 IP 与相同端口，点击“加入房间”。默认端口为 **UDP 24566**。
4. 各自选择角色并准备，房主点击“开始联机对战”，或按 `F5` / 手柄 `Start`。
5. 对局结束后可以返回联机大厅，重新准备；退出会断开连接。

每台电脑使用本机的 1P 单人键位或手柄（默认方向键/WASD、空格放弹、Q 技能）。联机中 `Esc` / `Start` 打开离开确认，对局继续进行。首次使用请允许游戏通过系统防火墙。网页版本不提供 ENet 局域网联机。

本机移动采用客户端预测，并按房主确认的输入校正位置；炸弹、技能结果、伤害与胜负仍由房主决定。两端需要使用相同的新版本。

v2.3 Windows 下载包为五位精灵与「未来」加入正背面行走步态，通灵形态的双腿与守护兽扇翼独立活动。两端都使用 v2.3 即可按上述步骤联机；详细更新见 [v2.3 发布说明](docs/发布说明-v2.3.md)，网络实现与验证范围见 [局域网联机说明](docs/局域网联机.md)。

## 六位精灵

每位精灵都有专属技能，冷却好了按键就能放。单人选角采用深色角色画廊：上方展示原素材海报，下方分别呈现角色档案、技能说明和六张 Q 版头像卡。海报带镜头呼吸、平滑鼠标视差、旋转光环与主题粒子，切换角色时交叉淡化并扩散能量环。选中头像带悬浮、光晕和边框流光，出发按钮带周期扫光；全部动效跟随角色主题色，布局和点击区域固定。技能键提示跟随键位设置和当前输入设备。

行走时，五位精灵的正、背面各有 16 个姿势循环，晶尾 / 闪电尾 / 叶片 / 烈焰鬃尾 / 羽尾按各自的相位摆动；「未来」的普通形态使用逐帧图集，通灵形态的双腿与守护兽扇翼分开推进，停步后双脚站稳、翅膀继续扇动。根目录的 `启动角色步态预览.bat` 与 `启动通灵预览.bat` 可以逐帧检查这些动作。

| 精灵 | 技能 | 效果 | 冷却 |
|---|---|---|---|
| 小诺 | 时光星域 | 冻结怪物和敌方炸弹 3 秒；对战中让对手减速 | 12 秒 |
| 阿修 | 暗刃瞬袭 | 向前突进最多三格，攻击沿途目标，突进时短暂无敌 | 15 秒 |
| 阿瑞 | 森罗守护 | 获得护盾，并让两格内的怪物停留 2 秒 | 14 秒 |
| 小炎 | 炎灭火舞 | 4 秒内吸收一次爆炸，再反弹给周围 5×5 的敌人 | 12 秒 |
| 小天 | 潜能洞察 | 显示炸弹范围，移动速度 +30%，持续 6 秒 | 12 秒 |
| 未来 | 迁境奇点 | 放弹减速 45%（2 秒）；放弹 6 次、击杀怪物或击倒对手即可**通灵**，通灵后减速 75%（3 秒）、范围 5×5 | 被动 |

## 七种道具

炸开软砖会掉道具，捡到立刻生效：

| 道具 | 效果 |
|---|---|
| 火力 | 炸弹爆炸范围 +1 |
| 炸弹 | 可同时放置的炸弹 +1 |
| 速度 | 移动速度 +10% |
| 生命果实 | 生命 +1 |
| 无敌星星 | 短时间无敌，碰到怪物能将其撞倒 |
| 护盾 | 抵挡一次伤害 |
| 推弹手套 | 可以把炸弹推出去 |

小心：火焰会烧掉地上的道具。

## 场景与敌人

三张主题场景随机出现，各有机关：

| 场景 | 机关 |
|---|---|
| 晨露森林 | 生命古树会落下林间果实 |
| 星汽工厂 | 中央反应炉旁有一条 24 格闭环传送带，会运送角色和炸弹 |
| 星糖游乐园 | 16 格旋转木马环道，绕完一圈可以得到护盾 |

小怪会索敌、寻路、主动炸开挡路的软砖、抢道具，投弹前还有 0.7 秒前摇，会先确认自己能安全撤离。

## 操作

| 模式 | 玩家 | 移动 | 放炸弹 | 技能 |
|---|---|---|---|---|
| 单人（闯关 / 拆砖） | 1P | `↑↓←→` 或 `WASD` | `空格` | `Q` |
| 双人（同屏对战） | 1P | `↑↓←→` | `回车` | 右 `Shift` |
| 双人（同屏对战） | 2P | `WASD` | `空格` | `F` |
| 联机（两台电脑） | 本机角色 | `↑↓←→` 或 `WASD` | `空格` | `Q` |

其他按键：

- 离线模式 `Esc` / `P` 暂停，`R` 重开本局，`M` 静音；`F11` 切换全屏
- `Tab` 切换 1P 备用键位（`IJKL` / `U` / `O`）
- 菜单和结算界面可以直接用鼠标点，`回车` 确认

**手柄**：插上就能用，菜单里可以选「自动 / 只用键盘 / 只用手柄」，也能重绑按键、调摇杆死区。

## 下载与运行

1. 到 [Releases](https://github.com/Panyusure/BombitGodot/releases/latest) 下载 `BombIt-Godot-v2.3-win64.zip`。
2. 解压到任意目录，双击 **`启动游戏.bat`**（或直接运行 `BombitGodot.exe`）。
3. `BombitGodot.exe` 和 `BombitGodot.pck` 必须放在同一目录，别只拷一个。

> 第一次运行如果被 Windows SmartScreen 拦住，点「更多信息 → 仍要运行」即可。

想回顾之前的对局，点菜单右上角的**「对局回放」**，可以播放 / 暂停、切倍速、逐帧、拖动定位。
