# Q版泡泡堂 · BombIt v2.3

角色真的走起来了：五位精灵与「未来」的普通形态换上正、背面各 16 个姿势的步态，通灵形态的双腿和守护兽扇翼各自活动。原立绘、显示尺寸、脚底锚点、碰撞与技能数值全部保持不变，闯关、计时拆砖、同屏双人和局域网双人对战照旧。

## 下载与运行

下载 **`BombIt-Godot-v2.3-win64.zip`**，完整解压后双击 **`启动游戏.bat`** 或 `BombitGodot.exe`，无需安装 Godot。主程序与 `BombitGodot.pck` 必须放在同一目录。

同页附带 `SHA256SUMS.txt`，可校验下载包。Windows 64 位绿色包包含 CLI、MCP 和对局回放功能。

## 本版更新

### 五位精灵：逐帧步态与附属动态

小诺 / 阿修 / 阿瑞 / 小炎 / 小天现在都有正、背面各 16 个主动作姿势的行走循环，并各自带有独立的附属动作：

| 角色 | 步态 | 附属动作 |
| --- | --- | --- |
| 小诺 | 轻盈跳步，短肢交替抬落 | 晶尾围绕根部回摆，前臂反向配合 |
| 阿修 | 紧凑快步，小幅重心起伏 | 闪电尾保持形状回摆，护臂随步幅配合 |
| 阿瑞 | 沉稳短步，重心缓慢交替 | 两侧叶片披摆有不同滞后，双臂轻摆 |
| 小炎 | 蓄力快步，较高抬脚与推步 | 烈焰鬃尾跟随，焰甲小幅配合 |
| 小天 | 轻踏滑行，小步幅交替 | 羽尾浮动、蓝色发梢轻摆、羽摆配合 |

- 用网格变形代替整图替换：`CharacterMotionProfiles.gd` 记录每个角色正背面的腿部落点、附属部件根部与保护区域，`CharacterMotionRig.gd` 缓存 16 个主动作姿势和 32 个附属姿势；每个角色实例拥有独立可变网格，只读缓存共享。
- 附属动作有自己的时钟：行走时随步幅摆动，停下后平滑回落到待机幅度。向上播背面，向下 / 右播正面，向左翻转正面；转向时步态与附属相位都保持连续。
- 步频沿用各角色原有的 `motion.stride`，并随速度道具、潜能洞察和减速效果实时变化；停步后双脚归位。
- 这五个角色原来叠在整张立绘上的弹跳与压扁已关闭，避免和网格步态重复；受击、护盾、死亡淡出和技能特效仍走原有流程。

### 未来：普通形态 16 帧行走

- 新增 `assets/characters/animations/weilai/walk_front.png` 与 `walk_back.png`：4×4 图集、每帧 256×320、透明无损、无 mipmap。
- `WeilaiWalk.gd` 缓存 16 张 `AtlasTexture`；向上播背面，向下 / 右播正面，向左翻转正面，停步切回原待机立绘。
- 帧内内容高 296，脚底锚点 (0.5, 0.9625)，渲染时补偿回原站立基线；觉醒形态保持原样。

### 未来 · 通灵形态：双腿步态与守护兽扇翼

- `WeilaiSpiritRig.gd` 直接以原 RGBA 立绘驱动 2D 网格，缓存 16 个腿部姿势；双腿正、背面循环，步频随加速、减速变化。
- 守护兽双翼绕肩部舒展、收拢，翼梢略滞后；翅膀使用独立时钟——行走时约 1.45 次/秒，待机时约 1.1 次/秒。停步后双脚站稳，翅膀继续活动。
- 耳机、面部、脚部与通灵圆盘设有保护区域，局部变形不会碰到这些部位；通灵柔光继续复用原有的离线 SDF，不逐帧重新烘焙。

### 预览工具

- 新增 `启动角色步态预览.bat`（`character_walk_preview.tscn`）：`1`～`5` 选角色，`Tab` 轮换，`空格` 切行走 / 待机，`S` 慢放，`A` 开关技能特效，`←` / `→` 翻转，正背面同屏，`Esc` 退出。
- `启动通灵预览.bat` 同步升级：方向键切换朝向并原地行走，`W` 切换自动步态，`空格` 播通灵爆发，`A` 开关柔光，`S` 慢放，`R` 重置。

### 回归入口

- `tools_test_locked.cmd` 把三组新测试加入默认套件，一次跑完全部 13 组。

## 和朋友联机

1. 两台 Windows 电脑都下载本次 **v2.3**，完整解压，连接同一个局域网。
2. 主菜单选择「联机对战」，一人点击「创建房间」。
3. 另一人填写大厅显示的房主局域网 IP 和相同端口，点击加入；默认端口 **UDP 24566**。
4. 各自选角并准备，双方就绪后由房主点击「开始对战」，或按 **F5 / 手柄 Start**。

每端默认使用方向键 / WASD 移动、空格放弹、Q 技能，也支持手柄。首次系统询问网络权限时，请允许在专用网络通信。详细连接说明见包内 `docs/局域网联机.md`。

## 已知限制

- 步态由原立绘的网格变形生成，不是新绘制的人类长腿：原图本身就是预合成的短肢造型，因此表现为短肢交替、跳步或轻踏滑行，没有新增肢体纹理。
- 只有移动状态播放步态，角色没有独立的跳跃动作。
- 目前支持两人局域网桌面对战，没有公网穿透、房间自动发现、观战或对局中途续接。实际连接受路由器隔离与防火墙影响。网页版本不提供 ENet 联机。
