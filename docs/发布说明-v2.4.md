# Q版泡泡堂 · BombIt v2.4

三张主题地图换上新的 Q 版场景美术，软硬砖紧密贴合格位；游乐园中央旋转木马改为 MiniMax H3 生成的循环动画。

## 下载与运行

下载 **`BombIt-Godot-v2.4-win64.zip`**，完整解压后双击 **`启动游戏.bat`** 或 `BombitGodot.exe`，无需安装 Godot。主程序与 `BombitGodot.pck` 必须位于同一目录。附带 `SHA256SUMS.txt` 供校验下载包。

## 本版更新

- **三主题地图美术**：森林采用云团树冠、奶油色石墙和圆润木箱；工厂采用薄荷绿玩具机壳、大齿轮和暖色包装箱；游乐园采用星纹陶瓷墙与彩色礼盒。地面、中央设施基座和工厂传送带配色同步调整。
- **收紧砖块间距**：软砖、硬墙按有效砖体边界取图，铺满 48×48 格位，相邻格接缝约 0.7 像素，保留倒角和接触边，让相邻砖块形成连续的空间。
- **旋转木马运行动画**：中央静态木马亭替换为 32 帧透明图集，以 12.8fps 播放，2.5 秒循环。动画随游戏时间推进，暂停时停帧，回放跳转时同步定位。
- **地图缓存修复**：清空对局时移除保留的砖块绘图节点，避免上一张地图残留。木马逐帧绘制不触发地板、硬墙或软砖缓存重建。
- **地图预览工具**：源码附带 `启动地图美术预览.bat`，按 `1 / 2 / 3` 切换主题，`Esc` 退出，使用真实地图生成与游戏渲染链路。

地图布局、出生保护、碰撞、炸弹阻挡、道具掉落和场景机关沿用现有规则。四种模式、六位精灵、角色步态、CLI、MCP 和回放功能继续包含在本版中。

## 和朋友联机

两台 Windows 电脑均使用 **v2.4** 并连接同一局域网。主菜单选择「联机对战」，一方创建房间，另一方填写房主 IP 和相同端口（默认 **UDP 24566**）加入；各自选角并准备后，由房主开始对战。详细操作见 [局域网联机说明](局域网联机.md)。
