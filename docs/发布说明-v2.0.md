# Q版泡泡堂 · BombIt v2.0

新增局域网双人对战与客户端移动预测，保留闯关、计时拆砖、同屏对战三种原有模式。

## 下载与运行

下载 **`BombIt-Godot-v2.0-win64.zip`**，完整解压后双击 `启动游戏.bat` 或 `BombitGodot.exe`。游戏主程序和 `BombitGodot.pck` 必须保留在同一目录。附带 `SHA256SUMS.txt` 可校验下载包。

## 本版更新

- **第四种独立模式「联机对战」**：通过房主局域网 IP 创建、加入房间，独立选角与准备，双方就绪后由房主开局；支持结算返回大厅、断线提示、退出后继续离线游玩。
- **房主权威同步**：角色、炸弹、连锁爆炸、地图、道具、伤害与胜负统一由房主处理，两端同步显示。
- **客户端移动预测**：本机移动立即反馈；根据房主确认的输入重放、校正位置，改善高延迟下的移动手感。
- **全屏与设置**：可在设置中切换全屏，保留 F11 快捷键；暂停界面增加设置齿轮。
- **界面调整**：移除旧版本小字，修正单人角色名遮挡，增强双人选角动效与全屏背景，联机大厅采用一致的美术风格。
- **玩法修复**：修复敌方在传送带与普通地面交界处卡住的问题。
- 保留原有震动方案。

## 两台电脑如何联机

1. 两端都安装本次 v2.0，连接同一局域网。
2. 主菜单进入「联机对战」，一端创建房间。
3. 另一端输入大厅显示的房主局域网 IP，使用相同端口加入，默认 **UDP 24566**。
4. 各自选择角色并准备，房主点击开始对战或按 F5 / Start。

每端沿用本机单人键位或手柄（默认方向键 / WASD、空格放弹、Q 技能）。联机中 Esc / Start 打开离开确认，对局继续。系统首次询问时需允许游戏在专用网络通信。

## 验证与限制

- 源码回归：9 组测试合计 405 项检查，另有 CLI 核心 20 项，均为 `FAILURES=0`。
- 联机回归包含两个独立游戏进程的 ENet 对局、炸弹连锁、道具、结算、断线重连及返回三种离线模式。
- 预测测试包含每方向 150 ms 延迟、抖动、20% 输入丢包、重复和乱序；这些是模拟条件，不代表所有实际网络。
- 尚未在两台物理电脑之间完成实机联测，实际连接还受路由器隔离和防火墙影响。
- 当前支持两人局域网桌面对战；没有公网穿透、房间自动发现、观战或对局中途续接。双方须使用相同协议版本。
- 仅预测移动；放弹、技能结果、伤害和胜负仍需等待房主确认。

详细说明见包内 `docs/局域网联机.md`。
