# 未来通灵形态：步态与守护兽扇翼

双腿正、背面各16个姿势循环。向上使用背面；向下/右使用正面；向左翻转正面。步频随加速、减速变化，停步后双脚归位。

守护兽双翼绕肩部舒展、收拢，翼梢略滞后。翅膀用独立时钟：行走时每秒约1.45次，待机时约1.1次。切换正背面保持两个相位连续。耳机、面部、脚部和通灵圆盘的保护区域限制局部变形。

游戏仍按现有规则触发通灵（放弹6次、击杀敌人或击倒对手）。普通未来步态和另外五位角色保持原样。

直接检查：双击项目根目录`启动通灵预览.bat`。默认原地行走；W切换自动步态，关闭后松开方向键可检查待机扇翼。方向键切换朝向/原地行走，S慢放，A开关柔光，空格播放通灵爆发，R重置，Esc退出。

实现：`WeilaiSpiritRig.gd`以原RGBA立绘驱动2D网格，缓存16个腿部姿势，独立更新扇翼顶点；不替换原图，不生成新肢体，不更改碰撞或技能数值。`EntityView.gd`在原本的立绘绘制位置绘制网格，保持阴影、护盾、受击及通灵前景的顺序。柔光复用原有离线SDF，不逐帧重新烘焙。

高分辨率透明序列、待机扇翼序列、图集、5秒MP4：`E:/MinimaxH3/deliverables/weilai_spirit_walk/`。视频是由游戏同一套骨骼代码原生渲染；游戏实时扇翼与腿部相位各自推进。导出的16帧用于素材审阅，游戏直接运行网格，无需加载额外大图集。

验证入口：`tools_test_locked.cmd test_weilai_spirit`。另复测`test_weilai_walk`、`test_art`、`test_core`和`test_play`。网格动态更新接口：[Godot ArrayMesh 文档](https://docs.godotengine.org/en/4.5/classes/class_arraymesh.html)。
