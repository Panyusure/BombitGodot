# Q版泡泡堂 · BombIt v1.0

经典炸弹人玩法，Q 版画风：放炸弹、炸软砖、抢道具，把怪物和对手一起送上天。

第一个正式版本，放出来给大家玩。

## 下载

**Windows 绿色包**：`BombIt-Godot-v1.0-win64.zip`

1. 解压到任意目录；
2. 双击 **`启动游戏.bat`**（或直接运行 `BombitGodot.exe`）。

免安装，删掉文件夹就卸载干净。`BombitGodot.exe` 和 `BombitGodot.pck` 要放在同一目录。
第一次运行如果被 Windows SmartScreen 拦住，点「更多信息 → 仍要运行」即可。

## 这一版有什么

**三种模式**

- **闯关模式**：十关冒险，清光怪物进下一关；第 5 关和第 10 关是鲁鲁旦 BOSS 战，8 点生命、试探 / 认真 / 暴走三阶段，暴走时会放毒刺、还能炸掉硬墙。
- **计时拆砖**：180 秒内炸光全场软砖，倒计时和剩余砖数都显示在屏幕上。
- **同屏对战**：两人一个键盘，先得 2 分获胜。

**六位精灵，各有技能**：小诺「时光星域」冻结怪物与敌方炸弹；阿修「暗刃瞬袭」突进攻击并短暂无敌；
阿瑞「森罗守护」给护盾并定住周围怪物；小炎「炎灭火舞」吸收一次爆炸再反弹；
小天「潜能洞察」显示炸弹范围并加速；未来「迁境奇点」靠放弹与击杀累积**通灵**，通灵后减速更强、范围更大。

**七种道具**：火力 +1、炸弹 +1、速度 +10%、生命果实、无敌星星、护盾、推弹手套（火焰会烧掉地上的道具）。

**三张主题场景随机出现**：晨露森林（古树落果）、星汽工厂（24 格闭环传送带运送角色与炸弹）、
星糖游乐园（16 格旋转木马环道，绕完一圈得护盾）。

**其他**：小怪会索敌、寻路、炸开挡路软砖、抢道具；菜单 / 关前敌情档案 / HUD / 暂停 / 结算完整；
5 首配乐与 19 个音效；菜单右上角「对局回放」可播放、暂停、切倍速、逐帧、拖动定位。

**这一版新增**

- 双人对战做了独立的**选角准备室**：两人各选各的角色、各自按准备，都准备好才能开局，不再互相顶掉角色。
- **手柄即插即用**：可选自动 / 只用键盘 / 只用手柄，能重绑键位、调摇杆死区，一人手柄一人键盘也可以。

## 操作

| 模式 | 玩家 | 移动 | 放炸弹 | 技能 |
|---|---|---|---|---|
| 单人（闯关 / 拆砖） | 1P | `↑↓←→` 或 `WASD` | `空格` | `Q` |
| 双人（同屏对战） | 1P | `↑↓←→` | `回车` | 右 `Shift` |
| 双人（同屏对战） | 2P | `WASD` | `空格` | `F` |

`Esc` / `P` 暂停，`R` 重开本局，`M` 静音，`F11` 全屏，`Tab` 切换 1P 备用键位；
菜单和结算界面可以直接用鼠标点，`回车` 确认。
