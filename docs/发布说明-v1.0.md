# v1.0 发布说明

把 HTML5 Canvas 原作《Q版泡泡堂 BombIt v2.3》完整移植到 **Godot 4.7.2** 的首个正式版本。

## 下载

- **Windows 绿色包**：`BombIt-Godot-v1.0-win64.zip`（87.8 MB，SHA256 `03C161E6FBDB4A2DF723C5C4CDB375C3CBE46904E443E6BDBF9C0F9A486C8CF1`）

解压后双击「启动游戏.bat」，或直接运行 `BombitGodot.exe`（必须与 `BombitGodot.pck` 同目录）。
首次运行若被 SmartScreen 拦截，选「更多信息 → 仍要运行」——这是未签名的自制程序，属正常现象。

## 本次内容

三种模式、六位精灵、十关冒险、三主题随机场景、道具、小怪与鲁鲁旦 BOSS 战、菜单 / 关前档案 /
HUD / 暂停 / 结算、配乐与音效，全部用 GDScript 重写，不依赖浏览器或 Web 技术。

相对上一版提交，这一版新增：

- **双人选角准备室**：两名玩家按各自设备独立选角与准备，不再互相改写角色；
  双方确认 + 均已准备 + 控制方式有效 + 角色不重复，才允许开局。
- **输入设置**：自动 / 只用键盘 / 只用手柄；手柄设备稳定分配（断开 1P 不会把 2P 的手柄挪给 1P）；
  摇杆死区可调；键盘与手柄键位重绑定，落盘到 `user://settings.cfg`。
- 菜单 / HUD / 结算 / 回放界面按原作继续对齐，设置页复用准备室。
- 绿色包补齐 CLI（`启动CLI.bat`）与 MCP（`mcp/bombit-mcp.json`）入口。
