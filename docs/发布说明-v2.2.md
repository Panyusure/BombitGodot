# Q版泡泡堂 · BombIt v2.2

六位精灵的超大宣发海报登上选角界面，主菜单补上了退出游戏；「未来」连发炸弹时的掉帧也修掉了。闯关、计时拆砖、同屏双人和局域网双人对战全部保留。

## 下载与运行

下载 **`BombIt-Godot-v2.2-win64.zip`**，完整解压后双击 **`启动游戏.bat`** 或 `BombitGodot.exe`，无需安装 Godot。主程序与 `BombitGodot.pck` 必须放在同一目录。

同页附带 `SHA256SUMS.txt`，可校验下载包。Windows 64 位绿色包包含 CLI、MCP 和对局回放功能。

## 本版更新

### 单人精灵选择：超大展示海报

- 六张宣发海报（诺亚 / 修尔 / 阿瑞斯 / 龙炎 / 帝释天 / 未来）入游戏：`tools_prepare_posters.py` 自动裁掉素材自带的黑边、等比缩到 2800px 宽，输出 WebP 到 `assets/characters/poster/`，六张合计约 1.9MB。
- 选角界面改成**统一画框**：六位精灵共用同一个 720×338 画框，尺寸完全一致；每张海报只改取景（人物落在哪、放大多少），翻页时不会跳。
- 说明文字浮在海报上：编号 / 属性 / 大名 / 称号在左，技能 / 说明 / LORE 在右，压在海报下沿的字幕带上，背后仍能看见画面。
- 动效：进场拉幕 + 镜头拉远；换人时闪白、两道冲击环、放射速度线（都裁在画框内）、新旧海报交叉溶解；常驻缓慢推镜、扫光与浮尘。连按方向键会自动跳过闪白，避免连续爆闪。

### 主菜单：退出游戏

「进入精灵选择」正下方新增**退出游戏**。点一次进入待确认（2.6 秒倒计时），再点一次才真正退出；点别处、按 Esc 或等待超时都会撤销，防止误触。鼠标、键盘方向键、手柄都能操作。

### 性能：连发炸弹不再掉帧

「未来」每放一颗炸弹会生成一个通灵脉动特效，两处绘制开销被修掉：

- 径向光晕贴图的缓存键里混进了每帧变化的整体透明度，导致每个脉动特效**每帧**重新烘一张 160×160 贴图。改成色阶只描述形状、透明度走顶点色，形状只烘一次。
- 虚线法环原来是「每段虚线一次绘制调用」（半径 140 的一圈约 80 次），合并成一次 `draw_multiline`。

同机 1080×1044 实测：单个脉动特效 **2.5ms → 0.5ms**，8 个同屏 **19.9ms → 7.5ms**，绘制调用 **2209 → 601**；空场也从 4.7ms 降到 4.0ms（另外几处场景渐变本来也在每帧重建贴图）。

### 角色动效

- 玩家角色改为四相步态：触地压扁、顶点拉伸、重心横移、前进倾斜，替换原来单一的上下抖动。
- 六位精灵各有氛围层（时间 / 暗影 / 生命 / 烈焰 / 洞察，未来的通灵形态沿用 SDF 柔光）；静止时能量自动衰减，省掉大部分无意义重绘。

## 和朋友联机

1. 两台 Windows 电脑都下载本次 **v2.2**，完整解压，连接同一个局域网。
2. 主菜单选择「联机对战」，一人点击「创建房间」。
3. 另一人填写大厅显示的房主局域网 IP 和相同端口，点击加入；默认端口 **UDP 24566**。
4. 各自选角并准备，双方就绪后由房主点击「开始对战」，或按 **F5 / 手柄 Start**。

每端默认使用方向键 / WASD 移动、空格放弹、Q 技能，也支持手柄。首次系统询问网络权限时，请允许在专用网络通信。详细连接说明见包内 `docs/局域网联机.md`。

## 验证范围

- 源码回归 **436 项检查全部通过**：核心、玩法、美术、地图缓存、输入、选角准备室、传送带、显示、联机、移动预测十个套件，失败数为 0。
- 六张海报逐张离屏渲染检查；选角界面在独立副本里渲染了六帧成品，以及进场 / 换人时间轴，确认画框尺寸一致、文字可读。
- 连发炸弹基准如上（同机、关闭垂直同步、1080×1044 窗口）；这是该特效环节的局部数据，不代表所有设备按同一倍数提升。
- 打包程序 `--headless` 启动 120 帧，无脚本错误。

目前支持两人局域网桌面对战，没有公网穿透、房间自动发现、观战或对局中途续接。实际连接受路由器隔离与防火墙影响。网页版本不提供 ENet 联机。
