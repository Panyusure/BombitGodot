# 五角色步态与附属动态

五位角色正、背面各16个主动作姿势，另有独立附属动作。保留全部原始PNG和各自技能特效，沿用原有显示高度、脚底锚点、碰撞与技能规则。

| 角色 | 步态 | 附属动作 |
| --- | --- | --- |
| 小诺 | 轻盈跳步，短肢交替抬落 | 晶尾围绕根部回摆，前臂反向配合 |
| 阿修 | 紧凑快步，小幅重心起伏 | 闪电尾保持形状回摆，护臂随步幅配合 |
| 阿瑞 | 沉稳短步，重心缓慢交替 | 两侧叶片披摆有不同滞后，双臂轻摆 |
| 小炎 | 蓄力快步，较高抬脚与推步 | 烈焰鬃尾跟随，焰甲小幅配合 |
| 小天 | 轻踏滑行，小步幅交替 | 羽尾浮动、蓝色发梢轻摆、羽摆配合 |

向上使用背面；向下/右使用正面；向左翻转正面。步频沿用各角色原有motion.stride并响应加速/减速。转向保持主动作与附属动作相位；停步主动作归位，附属幅度平滑减弱到待机水平。死亡沿用原来的淡出/摇摆表现。

## 直接预览

项目根目录`启动角色步态预览.bat`：1～5选择角色，Tab轮换，空格切换行走/待机，S慢放，A开关技能特效，左右方向键查看翻转，Esc退出。正面和背面同时显示，使用游戏中的EntityView。

## 实现

- `CharacterMotionProfiles.gd`：10套正背面源坐标绑定、短肢落点、附属部件根部和保护区域。
- `CharacterMotionRig.gd`：缓存16个主动作姿势和32个附属姿势，附属相位连续插值；每个角色实例有独立可变网格，共享不可变缓存。
- `EntityView.gd`：在原立绘的绘制位置接入实时网格，关闭重复的整图弹跳/压扁；保留原特效、深度和受击流程。未来的普通形态和通灵形态仍走已完成的独立实现。

原图使用预合成短肢/悬浮姿势，因此为短肢交替步、跳步或轻踏滑行，不人为加成人类长腿，也没有生成新的肢体纹理。
