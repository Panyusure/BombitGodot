普通形态未来：向上播放背面16帧，向下/右播放正面16帧，向左翻转正面。停步切回对应原始待机立绘。觉醒形态及其他五个角色沿用现有表现。

- 资源：`assets/characters/animations/weilai/walk_front.png`、`walk_back.png`。
- 图集4×4，每帧256×320，透明背景，无损导入，无mipmap。
- `scripts/WeilaiWalk.gd` 缓存AtlasTexture；`EntityView.gd` 根据真实移动状态切换。
- 帧内内容高296，脚底锚点(0.5,0.9625)，渲染时补偿待机脚底基线。
- 步频沿用未来的motion.stride/TAU并随加速、减速效果变化；转向保持步态相位，停下重置。
- 普通行走关闭原有整图弹跳、倾斜、压扁叠加，保留受击、护盾、死亡及觉醒效果。
