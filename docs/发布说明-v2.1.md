# Q版泡泡堂 · BombIt v2.1

三张主题地图更精致，炸砖更新更轻快。保留闯关、计时拆砖、同屏双人和局域网双人对战，约上小伙伴一起玩！

## 下载与运行

下载 **`BombIt-Godot-v2.1-win64.zip`**，完整解压后双击 **`启动游戏.bat`** 或 `BombitGodot.exe`，无需安装 Godot。主程序与 `BombitGodot.pck` 必须放在同一目录。

同页附带 `SHA256SUMS.txt`，可校验下载包。Windows 64 位绿色包包含 CLI、MCP 和对局回放功能。

## 本版更新

- **晨露森林**：新增石径、苔草、小花与绿篱石台，细化蘑菇、树苗的渐变和古树装饰，加入轻盈萤光。
- **星汽工厂**：增加金属铺板、螺钉、导光管线与主题边墙，细化能源容器、反应炉装饰及蒸汽动效。
- **星糖游乐园**：增加糖果铺装、星纹边墙和木马台灯饰，细化气球、棉花糖的明暗层次。
- **炸砖地图缓存优化**：独立保留每块软砖的绘图指令，炸掉一块砖时移除对应图元，其余砖块和中央设施不再重新生成几何；继续使用 2× 超采样静态地图纹理。
- **传送带动效优化**：箭头直接使用所在路径段的方向，减少逐帧重复寻路段的计算。
- 保留现有联机预测、房主权威同步、角色技能及四种游戏模式。

## 和朋友联机

1. 两台 Windows 电脑都下载本次 **v2.1**，完整解压，连接同一个局域网。
2. 主菜单选择「联机对战」，一人点击「创建房间」。
3. 另一人填写大厅显示的房主局域网 IP 和相同端口，点击加入；默认端口 **UDP 24566**。
4. 各自选角并准备，双方就绪后由房主点击「开始对战」，或按 **F5 / 手柄 Start**。

每端默认使用方向键 / WASD 移动、空格放弹、Q 技能，也支持手柄。首次系统询问网络权限时，请允许在专用网络通信。详细连接说明见包内 `docs/局域网联机.md`。

## 验证范围

- 10 组源码回归合计 **496 项检查**，包含联机、预测、双人准备室、传送带、输入、显示及新增地图缓存检查，全部通过。
- **18 项实际 2× 渲染对比**通过，覆盖三主题的初始地图、炸砖、恢复砖块、变体更新、清空软砖和切换主题；没有超过单通道 1/255 容差的差异。
- 本机基准中，炸砖的地图绘图指令更新 CPU 开销从约 **6–12 ms** 降到 **0.13–0.15 ms**。这是该环节的局部数据，不代表整体帧率按同一倍数提升，也不代表所有设备的表现。
- 联机回归使用同机两个独立进程的真实 ENet 连接，覆盖开局、移动、连锁爆炸、拾取、回合结算、返回大厅、断线重连；预测套件另覆盖模拟延迟、抖动、丢包、重复和乱序。

目前支持两人局域网桌面对战，没有公网穿透、房间自动发现、观战或对局中途续接；尚未在两台实体电脑之间完成实机联测。实际连接受路由器隔离与防火墙影响。网页版本不提供 ENet 联机。
